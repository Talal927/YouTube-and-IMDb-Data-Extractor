# Data Scraping and Analysis Project

This project demonstrates data scraping and analysis using Python, Selenium, and BeautifulSoup. It comprises three main tasks:

## Task 1: YouTube Channel Scraper
- **Objective**: Scrape video data from a YouTube channel.
- **Tools Used**: Selenium for automated browsing and data extraction.
- **Features**:
  - Extracts video titles, views, likes, upload dates, and comments.
  - Provides insights such as the average views in the last 30 days, the video with the highest likes-to-views ratio, and the correlation between likes and comments.

## Task 2: IMDb Top Movies Scraper
- **Objective**: Scrape data on top-rated movies from IMDb.
- **Tools Used**: BeautifulSoup for HTML parsing and data extraction.
- **Features**:
  - Extracts movie titles, ratings, release years, directors, and genres.
  - Calculates the average IMDb rating, most common genre, and identifies the director with the highest average rating.

## Task 3: Data Wrangling on Housing Prices
- **Objective**: Perform data wrangling on a housing prices dataset.
- **Tools Used**: Pandas for data manipulation.
- **Features**:
  - Discretizes age, normalizes data, removes outliers, and applies smoothing.
  - Performs linear regression to analyze the relationship between room count and median home value.
